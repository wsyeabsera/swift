Press <kbd>?</kbd> in the app for this list, always up to date.

| Keys | Does |
|---|---|
| <kbd>⌘K</kbd> | Focus Say |
| <kbd>↑</kbd> / <kbd>↓</kbd> in Say | Earlier requests |
| <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd> | Undo / redo |
| <kbd>Delete</kbd> | Remove the selected element |
| <kbd>Arrows</kbd> (<kbd>Shift</kbd> = 10 px) | Nudge a positioned element |
| <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> | Select child / parent |
| <kbd>Esc</kbd> | Deselect, or close a popover |
| <kbd>⌘D</kbd> | Duplicate the selected frame |
| <kbd>⌘0</kbd> | Fit everything |
| <kbd>⌘1</kbd> | Actual size |
| <kbd>Shift</kbd>+<kbd>2</kbd> | Zoom to the selected frame |
| Double-click a frame name | Rename it |
| <kbd>?</kbd> | This list |
