# Swift Canvas

An AI-native desktop design tool on the Claude Agent SDK (your Claude subscription). Speed of select-and-edit is the selling point; floating Apple-style glass over photo backdrops; works on any project (tvdash, research-radar, auto-label, itself).

- **V1 mockups (source of truth for the UI):** https://claude.ai/artifact/9JQD7AcKDh7FgGxhPurcxh (version 16, 22 boards)
- **Design files:** `~/Hobby/swift-canvas-design/project` (boards `*.dc.html`, `KIT.md` design system)
- **Preview + browser QA:** `node ~/Hobby/swift-canvas-design/qa/serve.mjs ~/Hobby/swift-canvas-design` (http://127.0.0.1:8797/), `cd ~/Hobby/swift-canvas-design/qa && node smoke.mjs`

Work is tracked as ws-command groups (project `swift`).
